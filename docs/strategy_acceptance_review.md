# ETF 日内策略验收审查

[← 返回项目首页](../README.md) · [查看完整项目介绍](project_overview.md) · [查看成本与成交假设](cost_and_execution.md)

当前固定组合测试只有 28 笔交易。开盘区间与噪声构造的是 `movement_budget_bp`（运动空间），不是条件期望收益。

- 开发期最高90%净收益下置信界：-6.16bp；未通过正下界门槛，因此测试结果只作诊断；
- 2bp 单边成本：平均每笔净收益 3.37bp；
- 2bp 下按交易日聚类、5日移动区块 bootstrap 的年化日均收益 95% 下界：-0.49%；
- 3bp 单边成本：平均每笔净收益 1.37bp；
- 5bp 单边成本：平均每笔净收益 -2.63bp。

## 验收门槛

- [ ] 开发期存在90%净收益下置信界大于0的候选
- [ ] 至少100笔锁定样本外交易
- [ ] 至少60个发生交易的样本外日期
- [ ] 2bp成本下区块bootstrap 95%下界大于0
- [x] 3bp单边成本下平均单笔净收益为正
- [ ] 5bp单边成本压力下平均单笔净收益为正

结论：**仅限研究，不具备部署证据**。
即使未来通过，也需要逐笔报价、盘口深度、基金申赎/停牌和券商真实费率验证；分钟 OHLC 不能证明可成交性。
