# Limitations

本项目主动保留限制说明，避免把研究框架误写成成熟实盘高频策略。

1. 本项目使用 1 分钟 OHLCV bar 数据，未使用 tick、逐笔成交、逐笔委托和订单簿数据，因此无法模拟真实高频交易中的盘口队列、挂单成交概率和低延迟执行。

2. 回测采用分钟级 bar execution 假设，不能完全等同于真实交易中的滑点、冲击成本、部分成交和交易限制。

3. A 股市场中可 T+0 交易的 ETF 数量有限，样本池规模小于股票横截面策略，限制了机器学习模型的训练样本多样性。

4. 本项目重点研究 long-only 短周期收益预测和下行风险识别，而真实日内量化交易中还常见统计套利、T0 回转、做市、跨市场对冲等方向。

5. 实证结果显示，直接预测 15min / 30min / 60min 正收益的稳定性较弱；相比之下，下行风险识别和交易成本敏感性分析更具解释价值。

6. 项目没有接入实时行情、交易网关、风控系统、订单管理系统和生产级监控，因此不能被理解为可直接部署的交易系统。

7. 因此，本项目应被理解为分钟级 ETF 日内量化研究框架，而不是成熟可直接实盘部署的高频交易系统。
