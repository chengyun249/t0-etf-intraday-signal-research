# 组合策略回测报告：ORB + Noise + Relative Value

## 1. 策略逻辑

本策略不是单独 ORB，也不是单独噪声边界，而是组合过滤：当日活跃 ETF、开盘区间突破、噪声边界突破、VWAP 确认、类别同步、相对价值不过热、收益空间覆盖成本后，下一根 1min bar 开多。退出采用 hard stop、VWAP stop、OR_high failure stop、trailing stop、take profit、max hold 和收盘前清仓。

## 2. 样本切分

- dev: 20250101 ~ 20250831
- test: 20250901 ~ 20251231
- main selection cost: 2.0bp 单边

## 7. 判断标准

- 如果 test 期 2bp 后仍为正，说明组合过滤比单一策略更有价值。
- 如果 test 期 3bp 后仍为正，说明有继续开发价值。
- 如果仍只在 0bp/1bp 有效，则说明当前 2025 池子上的 long-only 日内策略边际仍偏薄。
- 如果交易数太少，即使收益好，也不能直接视为稳定策略。
